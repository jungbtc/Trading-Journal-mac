온체인 매매일지 — Mac 앱 설치 안내

설치
1. DMG 파일을 엽니다.
2. Trading Journal을 응용 프로그램(Applications) 폴더로 끌어 놓습니다.
3. 응용 프로그램 폴더에서 Trading Journal을 실행합니다.
4. 매매일지 비밀번호를 만들고 설정 마법사에서 지갑 주소와 조회 전용
   거래소·제공업체 API 키를 추가합니다. 설정 코드는 앱이 자동으로 입력합니다.

macOS 12 Monterey 이상, Apple Silicon과 Intel Mac을 지원합니다.
Python이 앱에 들어 있어 터미널, Node, pip, 개발 도구를 설치할 필요가 없습니다.
실제 데이터 동기화에는 인터넷 연결과 본인의 제공업체 키가 필요합니다.
선택 기능인 AI를 사용하려면 Claude CLI를 별도로 설치하고 로그인해야 합니다.

내 데이터
매매일지, 설정, 키는 이 Mac의 다음 폴더에 저장됩니다.
~/Library/Application Support/Trading Journal/

Trading Journal 메뉴의 Open Data Folder를 누르면 폴더를 열 수 있습니다.
앱을 교체하거나 삭제해도 데이터 폴더는 남습니다.
대시보드는 이 Mac에서만 접속할 수 있습니다(127.0.0.1).
앱을 종료하면 동기화가 멈춥니다. 과거 내역을 가져오는 동안 앱을 열어 두세요.
마지막 창을 닫으면 앱도 종료됩니다. 정상 종료까지 몇 초 걸릴 수 있습니다.

비밀번호를 잊었다면 Trading Journal > Reset Login Password를 선택하세요.
로그인만 초기화하며 매매일지와 제공업체 키는 남습니다.
실행에 문제가 있으면 Trading Journal > Open Logs에서 로그를 확인하세요.
데이터 폴더는 따로 백업하세요. 이 폴더와 인증 정보는 다른 사람에게 보내지 마세요.

친구에게 공유하기
DMG 파일만 보내면 됩니다. 앱과 실행 환경이 들어 있으며,
개인 지갑, 매매일지, 비밀번호, API 키는 포함되어 있지 않습니다.
받는 사람은 설치 후 자신의 매매일지를 설정하면 됩니다.
